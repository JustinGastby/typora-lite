# Screenshots

README 默认引用本目录下的 **SVG 占位图**。换成真实截图时：

1. 导出 PNG / GIF / WebP（宽度建议 ≥ 1400px）
2. 按下面文件名保存（可覆盖，或改 README 里的扩展名）
3. 提交推送即可

| 占位文件 | 建议替换为 | 内容 |
|----------|------------|------|
| `hero.svg` | `hero.png` | 主界面全景：侧栏 + WYSIWYG 正文 |
| `wysiwyg.svg` | `wysiwyg.gif` | 边写边渲染短动图 |
| `themes.svg` | `themes.png` | 多主题对比 |
| `mermaid-math.svg` | `mermaid-math.png` | Mermaid / 公式效果 |

若使用 `.png` / `.gif`，请同步修改仓库根目录 `README.md` 中对应图片路径的扩展名。
